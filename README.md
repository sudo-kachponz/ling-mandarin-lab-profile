# Ling Chinese Lab

Profil dan landing page untuk Ling Chinese Lab, dibangun dengan Vite + React + TypeScript + Tailwind.

## Pengembangan

```sh
npm install
npm run dev
npm run build   # produksi
npm run preview # pratinjau build
```

## Struktur Penting
- `src/` komponen, halaman, dan aset utama.
- `public/` aset statis yang dirujuk langsung di HTML (favicon, og image).

Internal project.
